# Benchmark reports

Generated by the harness after **two real live runs** on the Intel Mac:

```bash
dotnet run --project benchmarks/Issue8.NluBenchmark -- report --runs run1,run2
```

Expected files, both committed as the Issue #8 evidence:

```text
reports/<model-slug>-intel-mac.md
reports/<model-slug>-intel-mac.json
```

Each report contains the model tag, environment metadata, dataset/schema/prompt versions and
hashes, both run summaries, the combined metrics, every docs/PLAN.md section 13.3 gate with its
measured value, representative mismatches and the Issue #9 model recommendation.

The report command refuses dry-run artifacts, so this directory can never contain fixture
numbers presented as benchmark evidence.
